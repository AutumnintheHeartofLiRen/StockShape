# 个人 AI 股票研究助手路线

目标是服务每天的个人研究：查本地事实、理解已有判定、整理观察记录，再逐步接入外部资料。保留普通桌面流程，让 AI 成为可选助手。

## 当前：只读 Agent 已接入

V1.3 已有独立研究 worker、桌面对话界面、通用 OpenAI 兼容 Chat Completions 接口和六个只读工具：搜索股票、行情状态、自选、日线均线、已有分析和候选列表。服务地址、模型名和密钥在软件中配置。

每轮固定截止日，行情按日期截断；已有策略结果必须与任务交易日匹配。工具只向模型提供有限行情和脱敏判定，不发送私有规则、参数、完整指标或源码。对话仅保留在当前窗口内，支持停止、超时与调用上限。

当前没有自动更新、自动分析、笔记库、新闻或财报检索。离线测试使用模拟模型服务；真实云模型需要使用者配置后自行验证兼容性。

## 下一步：积累可回查的研究记录

用 SQLite 保存用户审核过的研究笔记、观察事件、人工判断和后续结果；日线继续使用 CSV。为每条记录保存股票、交易日、来源和创建时间，支持单股检索与历史差分。

历史分析先增加按日保存的快照，再提供跨日比较。现有“最新结果”文件不足以还原任意历史日，不能把当前判定替代历史判定。后续收益属于事后信息，单独标记；跟踪期未结束时显示“未到期”。

## 随后：接入新闻、公告与财报

先选择可靠的数据来源和时间字段，保留原链接、发布时间和获取时间。区分事实、模型解释和用户判断，限制抓取数量；资料中的文本不能触发工具授权。

先解决日期、来源和重复资料，再评估相似案例与笔记的语义检索。没有实际检索需求时保持简单，不引入大型向量数据库或多 Agent 编排。

## 最后：加入明确授权的动作

只读流程稳定后，再让 Agent 提出保存笔记、调整自选、更新行情或运行分析的具体建议。用户在界面确认动作、范围和内容后，交给原有应用服务执行，并记录状态。

策略参数修改继续走本地设置。Agent 不拥有任意文件、shell 或交易下单权限。若以后需要控制策略使用资格，再评估服务端授权与计算；本地私有包不等于访问控制。

## 每阶段验收

- AI 未配置或不可用时，普通桌面功能继续工作。
- 数字能回查来源，历史研究不包含截止日之后的行情或判定。
- 缺失、取消、失败、调用额度耗尽与完成明确区分。
- 用固定合成案例和少量真实日常任务检验，再扩大工具权限与数据范围。
