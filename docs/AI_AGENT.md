# AI 研究助手

V1.4 的 AI 助手根据本地行情、自选和已保存分析回答问题。它可以自主选择六个只读工具，不会更新行情、重跑选股、修改自选或参数、保存文件或下单。

## 首次配置

1. 打开“AI 研究助手”，点击“模型设置”。
2. 选择“云端 API”或“本地模型”，按下方说明配置服务与模型。两种模式都要求服务兼容 OpenAI Chat Completions，并支持函数工具调用。
3. 本地模式可点击“检测连接并读取模型”，选择返回的模型；也可以手动填写模型名称。
4. 保存设置，输入问题，点击“开始研究”。保存配置本身不会调用模型；读取列表和检测连接只请求模型列表，不发研究问题、不触发推理。

### 云端 API

填写供应商提供的服务地址、模型名称和 API key。服务地址可填写 API 根地址、带版本的基础地址或完整 `/chat/completions` 地址，例如 `https://你的服务地址/v1`。远端使用 HTTPS。供应商专用 SDK、只支持 Responses 或不支持工具调用的接口暂不适用。

### 本地模型

先安装并启动本地模型服务，再在软件中选择对应预设：

| 服务 | 默认基础地址 | 准备工作 |
| --- | --- | --- |
| Ollama | `http://127.0.0.1:11434/v1` | 在 Ollama 中下载支持工具调用的模型，启动本机服务 |
| LM Studio | `http://127.0.0.1:1234/v1` | 下载并加载模型，在 Developer 页面开启本地服务 |
| 自定义本地服务 | 自行填写回环地址 | 启动兼容 Chat Completions 与工具调用的本机服务 |

本机回环服务可以不填密钥；服务开启认证时仍应填写其要求的密钥。模型名称以服务返回的模型 ID 为准。GGUF 等模型权重的下载、加载、显存和上下文设置由 Ollama、LM Studio 或所选运行器管理，StockShape 连接已启动的服务，不直接加载权重文件。

Ollama 的接口范围见[官方兼容文档](https://docs.ollama.com/api/openai-compatibility)；LM Studio 的启动方法见[本地服务文档](https://lmstudio.ai/docs/developer/core/server)。本地运行器、模型和聊天模板均需支持工具调用，LM Studio 的原生支持说明见[工具调用文档](https://lmstudio.ai/docs/developer/openai-compat/tools)。

“检测连接并读取模型”成功仅表示模型列表接口可访问，不能证明所选模型已经加载、推理成功或支持工具调用。LM Studio 开启即时加载时，列表可能包含尚未加载的已下载模型，见[官方模型列表说明](https://lmstudio.ai/docs/developer/openai-compat/models)。首次使用仍应从单只股票的小问题开始，检查回答中的真实工具过程。

同一模式且同一服务地址下，API key 留空可保留已有值；更换地址或模式时不沿用旧密钥。勾选“清除已保存的密钥”可主动删除；在设置窗口切回原模式时，可恢复该模式的地址和密钥草稿。配置保存在项目根目录 `.env.local`，不会进入公开导出。文件中的密钥是明文，本机备份也应按私密资料保存。不要把密钥填入聊天问题。

## 适合先问的问题

- “当前股票近期走势怎样？MA40 在哪里？本地数据更新到哪一天？”
- “查看我的自选股，概括已有分析与数据缺口。”
- “已有候选有哪些？这些结果与当前本地行情日期一致吗？”

“当前股票摘要”“自选股概览”“本地数据状态”按钮会填入问题，确认内容后点击“开始研究”。“新对话”清空本窗口上下文；关闭窗口后对话不保留。

默认以本地最新有效交易日为截止日，也可以取消勾选并指定历史日期。每次任务固定这个日期，行情只读截至该日的数据。截止日改变后会清空传给模型的旧对话上下文，历史消息仍可在窗口查看。分析缓存仅在保存交易日与任务日期一致时可用；缺失时在普通桌面先运行对应分析，再重新研究。当前没有任意历史策略重放、跨日策略快照或新闻财报数据。

## 阅读结果与控制任务

查询过程会显示正在使用的工具，结果附数据日期、来源与限制。本地日线不是实时行情；停牌、缺少记录、数据异常或缓存过期都会限制结论。完整策略版本、规则和参数留在本机，AI 仅收到脱敏判定。

研究与本地更新/分析任务互斥。“停止”会结束当前只读研究并忽略迟到结果；请求已经到达服务端时，停止不能保证服务端立即结束计算，云端也可能仍产生费用。达到调用上限、模型返回截断内容或查询失败时显示未完成/错误，缩小问题范围后重试。

## 高级设置

软件可直接设置连接模式、本地运行器、服务地址、模型、密钥和超时；其余上限在 `.env.local` 中调整。可参考根目录 `.env.example`，不要覆盖自己已有的密钥。非空同名进程环境变量优先于文件。

| 配置 | 默认 | 允许范围 |
| --- | --- | --- |
| `AI_PROVIDER` | `openai_compatible` | 当前仅此一种接口类型 |
| `AI_CONNECTION_MODE` | `auto` | `auto`、`cloud` 或 `local`；旧配置按地址自动识别 |
| `AI_LOCAL_RUNTIME` | `custom` | `custom`、`ollama` 或 `lm_studio` |
| `AI_TIMEOUT_SECONDS` | 45 秒 | 1～180 秒 |
| `AI_MAX_STEPS` | 6 | 1～12 轮模型调用 |
| `AI_MAX_TOOL_CALLS` | 12 | 1～32 次，含启动时的数据状态检查 |
| `AI_MAX_OUTPUT_TOKENS` | 1600 | 128～8192，每轮请求的输出上限 |

服务端仍可能施加自己的上下文、输出与额度限制，本地运行速度也取决于模型大小、量化与硬件。当前通用接口的流程测试使用模拟服务，不能代替对具体云模型或本地模型的兼容性验收。

云端模式会把问题、有限对话上下文和本次查询摘要发送到配置的服务端，包括相关股票、部分行情和脱敏选股判定。本地模式将这些内容发到本机回环地址，StockShape 不另行发送到云端；但本地服务自身是否转发取决于其配置，例如 Ollama 的本机服务也可以使用云模型，见[官方认证说明](https://docs.ollama.com/api/authentication)。需要纯本机推理时，应在运行器中选择实际下载到本机的模型。

两种模式都不会自动发送完整行情库、私有策略源码、参数文件或完整私有指标。自己在问题中输入的内容仍会发送给所选模型服务。
